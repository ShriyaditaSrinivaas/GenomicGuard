# GenomicGuard Data

This directory contains synthetic genomic data generated by the GenomicGuard pipeline.

## Files

After running `python scripts/generate_data.py`, you'll find:

- `genotypes.csv` — SNP genotype matrix (0/1/2 encoding)
- `clinical.csv` — Clinical phenotype features
- `phenotypes.csv` — Disease labels and risk scores
- `snp_metadata.csv` — SNP annotations and effect sizes
- `sample_metadata.csv` — Sample-level metadata

## Important

All data is **synthetically generated** and does not represent real patients.
The data structure mimics real genomic datasets (e.g., UK Biobank, 1000 Genomes)
for demonstration purposes.
